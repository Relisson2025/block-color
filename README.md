# Como Ativar a Página no GitHub Pages (2 Minutos)

Esta pasta contém:
1. `index.html` - Página oficial da Política de Privacidade (em Inglês e Português) para o Google Play Console.
2. `privacy.html` - Redirecionamento automático.
3. `app-ads.txt` - Arquivo obrigatório exigido pelo Google AdMob para verificar a propriedade do app e maximizar seus ganhos de anúncios.

---

### Passo a Passo no GitHub:

1. Acesse o seu GitHub: [https://github.com](https://github.com)
2. Crie um novo repositório público chamado, por exemplo: `block-color` (ou `<seu-usuario>.github.io`).
3. Faça o upload dos 3 arquivos desta pasta (`index.html`, `privacy.html`, `app-ads.txt`) diretamente na raiz do repositório.
4. No repositório no GitHub, clique em **Settings** (Configurações) -> aba lateral **Pages**.
5. Em **Branch**, selecione `main` (ou `master`), pasta `/ (root)` e clique em **Save**.
6. Pronto! Em 1 minuto sua página estará no ar na URL:
   `https://<seu-usuario>.github.io/block-color/` (ou `https://<seu-usuario>.github.io/block-color/privacy.html`)

> **Importante para o AdMob:**  
> Abra o arquivo `app-ads.txt` e troque `pub-XXXXXXXXXXXXXXXX` pelo seu ID de editor do AdMob.
